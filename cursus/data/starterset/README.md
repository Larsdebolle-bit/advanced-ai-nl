# Startset

Heb je nog geen eigen inputs? Dan start je hier.

## Wat staat hier?

- `voorbeeld-mailsorteerder/`: een klein, afgewerkt voorbeeld van een Build. Een prompt, een testset en een logboek.
- `mails.md`: twaalf verzonnen mails. Gebruik ze als testinputs als je zelf geen echte hebt.

## Wanneer gebruik je dit?

Alleen als je geen echte inputs hebt. Echte inputs zijn altijd beter.

Gebruik je de startset? Schrijf dat bovenaan je `test-set.md`. Je cijfer heeft dan een bovengrens. Dat staat in de Build-brief.

## Het voorbeeld kopiëren

Vraag je AI:

```
Kopieer ../../cursus/data/starterset/voorbeeld-mailsorteerder naar mijn map build/.
```

Pas daarna de labels aan aan jouw taak. Vervang de voorbeeldinputs door die van jou.

## De regel

Schrijf het juiste antwoord op vóór je de tool laat draaien. Niet erna. Achteraf beslissen wat juist was, is jezelf bedriegen.

Schrijf er ook bij waarom het juist is. Eén zin volstaat.
