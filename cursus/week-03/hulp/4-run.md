# 4 — Run 1

Plak: `Lees ../../cursus/week-03/hulp/4-run.md en help me verder.`

## Voor je AI

Draai de testinputs **niet zelf** in dit gesprek. Je hebt de juiste antwoorden gezien. Een test waarbij het model de antwoorden kent, meet niets.

Help de student zo:
1. Toon de prompt uit `build/` in één blok, klaar om te kopiëren.
2. Vraag welke vijf inputs eerst gaan. Minstens twee lastige.
3. Leg uit hoe één run gaat (hieronder). Wacht dan op de uitvoer die de student terugplakt, en zet die in de kolom Run 1. Precies wat het model zei, niet mooier.

## Eén run

- een **nieuw gesprek** per input
- je prompt erin, één input erbij
- **geen** web search
- in de Claude- of ChatGPT-app, in een incognito- of tijdelijk gesprek (anders laadt je geheugen mee), of in een terminal in een lege map. Niet in je studentenmap: daar leest je tool `context.md` mee
- nooit de hele testset in één keer: dan ziet het model de antwoorden

Klaar als: minstens vijf inputs hebben iets in de kolom Run 1. Volgende: `5-fouten.md`.
