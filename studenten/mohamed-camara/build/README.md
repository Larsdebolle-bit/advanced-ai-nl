# Receptenkiezer

## Wat doet deze tool?

De tool leest een foto van ingrediënten en vergelijkt die met een vaste lijst van 10 recepten. Hij toont welke recepten volledig mogelijk zijn en welke bijna mogelijk zijn, met de ontbrekende ingrediënten.

## Zo gebruik je de v1

1. Open een nieuw tijdelijk gesprek met een AI die foto's kan lezen.
2. Plak de tekst uit `prompt.md`.
3. Vervang de tijdelijke plaats voor de receptenlijst door jouw vaste receptenlijst.
4. Voeg één foto met ingrediënten toe.
5. Vergelijk het antwoord later met je eigen testset.

## Bestanden

- `taak.md`: wat de tool moet doen.
- `prompt.md`: de context die je aan het model geeft.
- `log.md`: wat je verandert en wat het resultaat is.
