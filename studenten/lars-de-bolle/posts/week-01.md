# Week 1 — Claude Code kende ik al, GitHub niet

## Wat heb ik tot nu toe met AI gedaan?

Ik werk al veel met Claude Code. Ik bouwde er een vault mee waarin ik reels
opsla en uitwerk, en ik gebruik het voor OpMaat, voor Elevio en voor een reisapp
voor Holiways. Alles met Claude Code in de terminal, niet met een browserchat.

## Wat verraste me vandaag?

Woensdag was ik niet in de les: mijn lessenrooster was nog niet in orde. Ik heb
de opzet vandaag ingehaald — account, fork, clone, eigen map.

Wat me opvalt: leuk dat we zulke dingen nu met school leren, met Claude Code en
GitHub. Met Claude Code werkte ik al heel veel, met GitHub minder. Ik liet Claude
Code vaak dingen voor mij doen op GitHub, zoals skills downloaden. Nu doe ik het
zelf en zie ik wat eronder zit: fork, clone, remote, commit, push, pull request.

## Welke richting wil ik uit?

Ik wil Elevio verder uitwerken. Ik ben daar nu bezig met een klant voor wie ik
een redelijk groot project mag doen, en daarop wil ik verder bouwen om mijn
bedrijf binnen AI en automatisatie uit te diepen. Ik hoop dat de lessen van dit
vak daarbij helpen en me nieuwe dingen leren die ik in het werkveld kan
gebruiken.
