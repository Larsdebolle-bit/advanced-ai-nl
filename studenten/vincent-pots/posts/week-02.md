# Week 2 — testruns van AI-agent

## Wat bouw ik?
de 5 vakpagina's van op canvas gaan er in en de deadlines voor die vakken komen er uit.


## Waarom een taalmodel?
het is een taalmodel het is geen vaste structuur of hoeveelheid van de input.


## Eén testinput
**Input:** de vakpagina Français des Entrepreneurs op Canvas (T05).

**Mijn juiste antwoord:** één opdracht, "L'entreprise de demain : travail en équipe", zonder datum. Dus: geen duidelijke deadline — zelf controleren.

**Wat de tool zei:**
- Run 1 vond twee opdrachten: de teamopdracht en het posten van de definitieve fiches (Phusis, The Skateroom, BeeODiversity).
- Run 2 vond er drie: ook de planning-, evaluatie- en feedbackpagina's.
- Beide runs gaven bij elke opdracht "geen duidelijke deadline — zelf controleren".

**Wat ik zag:** de tool vond meer dan mijn eigen lijst, en dat klopte. Maar Run 1 miste een opdracht die Run 2 wel vond. Dezelfde input geeft dus niet twee keer hetzelfde resultaat.
